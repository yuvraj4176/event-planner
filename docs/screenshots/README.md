# Screenshots

Put the screenshots for the main README in this folder.

Suggested file names, which match the commented-out images in the README:

| File | What to capture |
| --- | --- |
| `Home.png` | The Home page: header, hero and the showcase sections |
| `plan-form.png` | The Plan an event page with the form filled in |
| `plan-results.png` | A created plan, for example the Budget or Timeline tab |
| `chat.png` | The chat assistant open with a short conversation |
| `print.png` | The print preview of the plan sheet |

Tips:

- Use PNG files about 1200 to 1600 pixels wide, and keep each one under 500 KB.
- Capture in light mode for the clearest result, or one image per colour scheme.
- Do not show your API key, your `.env` file or personal details.
- After adding a file, remove the comment markers around its row in the main README.
